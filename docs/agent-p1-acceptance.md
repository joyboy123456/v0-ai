## B1 ObservationStore

- 代码：`lib/server/agent/perception/observation-store.ts`。
- API：注入 AssetQueryPort 和可选目录/时钟，通过 `get` 只读或 `getOrCompute` 合并计算。
- 缓存键绑定用户命名空间、assetId、当前 assetDigest 与 observerVersion；每次读取前鉴权。
- 复用 24h 常量及原子 JSON 写入；过期、损坏或错配返回 null，不从旧备份恢复观察。
- 仅回调中产生描述；身份、来源和时间由存储层写入。计算前后校验素材仍有效。
- 同进程跨实例合并计算；已成功缓存可跨重启复用；没有跨进程执行锁或 LRU。
