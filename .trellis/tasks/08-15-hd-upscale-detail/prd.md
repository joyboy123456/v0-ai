# 第四功能「高清放大细节图」— 前端界面先行

> 来源：用户提供的《服装细节图生成功能 PRD v1.0》全文（见本目录 info.md 附录 / 会话记录）。
> 本任务范围：只交付**前端界面**（创作主界面 + 任务进度与结果渲染），数据走本地 mock，后端接口后续任务再接。

## 1. 目标

在现有工作台（`components/workbench/`）中新增第四个功能入口 **「高清放大细节图」**（feature id：`garment-detail`），按 PRD 实现完整创作与结果界面，不接真实后端。

## 2. 范围内（本期做）

### 2.1 创作主界面（LeftPanel 新分支，独立表单组件）

按 PRD §3 用户流程组织表单：

1. **上传服装原图**（FR-1 前端校验部分）
   - JPG/PNG/WebP，单张 ≤ 20MB；前端提示边长建议 ≥ 1024px。
   - 复用现有上传组件（`upload-components.tsx`）与 `/api/assets/upload`（本地/OSS 已有），不做 STS 直传（后端任务）。
2. **抠图分类状态 + 分类确认/修正**（FR-3/FR-4 界面）
   - mock「自动识别中 → 识别结果」状态；分类选项按 PRD：`上装 / 下装 / 连衣裙 / 配饰 / 鞋包`；
   - 用户可手动改选分类。
3. **模型选择：标准版 / 专业版**（FR-5/FR-6）
   - 模型列表由 mock 的「模型版本列表接口」模块下发（`lib/garment-detail-models.ts`），含分辨率、推荐/默认标记，**前端不硬编码模型**；
   - 标准版：1K，默认选中；专业版：2K/4K。
4. **参考图（可选，≤3 张）**（FR-7/FR-8）
   - 提示「每张参考图生成 1 张结果」；输出数量 = 参考图数量，无参考图输出 1 张（FR-14）。
5. **自定义提示词（可选，≤103 字）**（FR-9/FR-10）+ **AI 追加描述开关**（FR-11，界面先行）。
6. **分辨率与比例**（FR-12/FR-13）
   - 分辨率选项随模型档位联动（标准 1K / 专业 2K、4K）；比例默认 1:1，可选 3:4、4:3。
7. **提交生成**：前端校验齐全后提交。

### 2.2 任务进度与结果渲染（复用 RightPanel 体系）

- mock 异步任务：`排队中 → 生成中 → 生成成功/失败`（PRD FR-16），前端本地 setTimeout 推进状态，复用现有任务卡片/轮询 UI；
- 展示预计等待时间文案与失败重试入口（FR-17 界面部分）；
- 结果网格：每张细节图带部位/场景 label，支持单张放大预览（缩放、拖拽）；预览内提供「原图对比」切换（FR-18 轻量版：原图/细节图并排或切换，局部定位框本期可选做）；
- 单张/批量下载入口沿用现有下载交互（mock 图可直接下载）；
- mock 结果图取自 `lib/yibai-demo-cases.ts` 现有 demo 资产。

### 2.3 集成点

- `lib/types.ts`：`FeatureType` 增加 `'garment-detail'`；新增分类/档位/参数类型与选项常量；`FEATURES` / `FEATURE_LABELS` / `FEATURE_WORKFLOWS` 补条目。
- `feature-sidebar.tsx`：第四入口 + 图标（ZoomIn 类）。
- `left-panel.tsx`：新增 garment-detail 分支，渲染独立表单组件 `garment-detail-form.tsx`（避免继续膨胀 3000+ 行的 LeftPanel）。
- `right-panel.tsx` / `image-task-card.tsx`：新 featureType 走通用渲染，必要时补分支。
- `workbench.tsx`：接线 mock 提交；移动端 `mobile-shell.tsx` 自动复用。

## 3. 范围外（后续后端任务）

- OSS STS 直传、真实抠图/分类服务、服务端提示词模板拼装（PRD §5）、模型推理、内容审核、计费、历史筛选服务端化、接口签名。
- mock 的模型列表/任务接口届时替换为真实 API（PRD §6 字段为参考）。

## 4. 约束（来自 AGENTS.md / 前端约定）

- 双主题：只用语义 token（bg-card / text-foreground 等），禁止新增硬编码亮色；深色预览舞台沿用 `bg-[#111315]`。
- 移动端断点 768px：hover 才显示的操作补 `max-md:opacity-100`；MobileShell 复用状态。
- 类型严格：新分支不得产生 `any`/`@ts-expect-error`。

## 5. 验收标准

1. 侧边栏出现第四功能，可切换，桌面三栏 + 移动端外壳均可用。
2. 表单完整：上传 → mock 分类确认 → 双档模型 → 参考图 ≤3 → 提示词 ≤103 字 + AI 追加开关 → 分辨率/比例联动 → 提交。
3. 提交后出现 mock 任务：排队/生成中进度可见，最终成功出网格结果，可放大预览、原图对比、下载；含一条 mock 失败案例可重试。
4. 参考图数量 = 输出数量；无参考图输出 1 张。
5. `pnpm tsc --noEmit`、`pnpm lint`、`pnpm build` 通过。
